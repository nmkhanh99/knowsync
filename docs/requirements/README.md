# Requirements

Nhóm tài liệu này giữ các requirement IDs canonical của KnowSync theo format `BRD-*`, `PRD-*`, và `FRD-*`.

Khi cần trace:

- product -> architecture: dùng `@doc:../architecture/...`
- requirement -> code: dùng `@symbol` exact như `@runIndex`, `@getDocVisualization`, `@startVizServer`
- implementation -> requirement: giữ nguyên exact IDs `BRD-*`, `PRD-*`, `FRD-*` trong docs, comments, docstrings
